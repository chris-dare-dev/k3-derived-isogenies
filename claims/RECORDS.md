# Tasks and records, claim by claim

Generated by `tools/claims.py tables`; do not edit. For every claim of [CLAIMS.md](../CLAIMS.md) that has tasks: each task with what its output is compared with, and the latest record of the task under the scheduler, if there is one. A task without a record reads "not re-run": the stored result is then the only support, and it is the original output, not a run of this repository.

A task is one command of a note's *Reproduce* section. "Compared with" names the stored files of the data archive ([DATA.md](../DATA.md)) and the mode of each comparison ([README.md](../README.md#what-a-task-does)), or the lines its output must contain. The verdict is **reproduced** when everything compared is identical, **checked** when there is no stored file but the output has the lines it must have, **ran** when the command ended and nothing was compared, and **differs** otherwise. A record names the day it was computed and the commit of the code.
